# 受試者動作觀察實驗

以 YOLOX 預訓練人物偵測器、官方 OC-SORT 追蹤器及 MediaPipe Pose，觀察單一選定目標的動作，提供 FHD 骨架預覽與原影片時間的 CSV 紀錄。

可觀察的項目包括：搖頭、左手／右手／雙手的小幅度快速揮舞、疑似趴桌，以及可見上半身離開原座位區。這是可調整門檻的影像規則實驗，**沒有年齡或情緒辨識，也不能僅憑動作判定不耐煩**。

## 安裝與執行

主要支援 Windows、Python 3.12。使用專案內獨立的 `.venv`，相依版本固定於 `requirements.txt`。`uv` 為可選工具；若沒有 `uv`，請先確認 `python` 指向 Python 3.12。

下載或 clone 儲存庫後，進入專案資料夾執行：

```powershell
.\setup_env.bat
.\run_pose.bat
```

也可直接雙擊 `run_pose.bat`；啟動檔會先檢查必要依賴，環境不完整時呼叫安裝流程。第一次安裝套件及下載缺少的模型需要網路。

本儲存庫**不附受試者影片、模型權重、虛擬環境、原始實驗紀錄或本機環境報告**。安裝時將預設 YOLOX-Nano 與 MediaPipe Pose Landmarker Lite 下載至本機 `models`；後續優先使用本機檔案。切換 Tiny 或 S 時才補下載對應模型，不需重新訓練。

將自己的影片放在專案本層即可依檔名順序播放；不遞迴掃描子資料夾。也可以指定單一影片或其他資料夾：

```powershell
.\run_pose.bat --input ".\videos\sample.mp4"
.\run_pose.bat --input ".\videos"
```

支援常見影片格式與中文檔名。不修改來源影片、不播放音訊，也不儲存映射影片或影格。輸出的 CSV 預設存於 `logs`。

命令列完整分析影片、不開啟預覽視窗：

```powershell
.\.venv\Scripts\python.exe -B .\experiment.py --input ".\videos\sample.mp4" --headless
```

`--headless` 仍會寫入 CSV，不必設定影格上限。只驗證片段時，可另外設定起始時間、影格數與輸出位置：

```powershell
.\.venv\Scripts\python.exe -B .\experiment.py --input ".\videos\sample.mp4" --headless --start-seconds 8 --max-frames 300 --output ".\logs\trial"
```

入口為 `experiment.py`；`pose_viewer.py` 保留為共用預覽模組。所有行為計時都使用**來源影片時間**，從第 8 秒開始分析仍記為第 8 秒，暫停不增加行為持續時間。解碼器時間戳不足時以影格位置與來源 FPS 推估；特殊可變影格率或時間資訊損壞的影片仍需核對時間精度。

## 預覽與操作

傳入 OpenCV 顯示的影像固定為 **1920 × 1080**，影片保留比例並補黑邊，右側顯示目標、追蹤、行為、影片時間與處理速度。顯示縮放不參與原影片座標下的幾何判斷。

依來源 FPS 控制播放；硬體處理不及時允許變慢，不保證原速。`--device auto` 在一般 pip OpenCV 環境使用 CPU；只有 OpenCV 建置與環境提供可用 CUDA DNN 後端時才能使用 `--device cuda`。

| 按鍵 | 操作 |
| --- | --- |
| 空白鍵 | 暫停／繼續。 |
| R | 結束目前事件、清除目標、動作基準與手動座位框，重新收集肩寬選人。 |
| S | 選取正常坐姿人物的追蹤範圍作為座位基準框；拖曳後 Enter 確認、Esc 取消。 |
| N | 下一部影片，清除追蹤與基準。 |
| Q／Esc／關閉主視窗 | 結束並關閉 CSV、影片、MediaPipe 與視窗資源。 |

## 選人、恢復與身分紀錄

黑幕或沒有可信人物時持續等待，不需要事先指定黑幕長度。初始化依 OC-SORT ID 收集約 **2 秒、至少 10 份有效肩寬樣本**，比較換算至原影片像素的左右肩距離中位數：

- 只有一人合格時，選定該人；其他人缺肩不會阻止初始化。
- 多人合格時，選肩寬較小者；候選差距不明顯時繼續收集。
- 缺肩、低信心或錯配樣本不會當成肩寬 0。

肩寬小不代表年齡小；成人距離鏡頭較遠、透視或遮擋都可能影響選人。選定後不會因體型排序改變而自動換人。

預設啟用以下三層恢復，全部使用來源影片時間；暫停不累計：

| 情況 | 預設處理 |
| --- | --- |
| 原目標沒有當幀有效人物偵測配對 | 立即解除鎖定並重新肩寬選人，設定為 `reselect_on_loss=true`、`auto_reset_seconds=0`。只有 OC-SORT 預測框不算有效觀測。 |
| 原 ID 仍被實際觀察到，但姿態連續不足 | 每隔約 **2 秒**重建該目標專用 MediaPipe VIDEO 實例，保留 ID、選人結果及已完成的坐姿／座位區基準。 |
| 原 ID 仍被實際觀察到，但姿態連續不足達 **10 秒** | 解除鎖定並重新收集肩寬；`pose_reselect_seconds` 是獨立的總失敗門檻，2 秒重建不清除這段失敗時間。 |

有效的鎖定姿態恢復後，連續姿態失敗計時歸零。姿態不足包含沒有可用骨架或分析所需關鍵點不足；相關骨架行為回報未知。離席的離開分支可使用有效人物框獨立判斷，歸席需要骨架確認；人物消失、遮擋、重建或重選本身都不是離席成立證據。

完整重選會清除舊目標、肩寬樣本及動作／坐姿／座位區校正，也取消前一代的指定座位框，使用當前有效 OC-SORT 人物框逐人裁切，再以 MediaPipe IMAGE 模式重新收集約 **2 秒、至少 10 份有效肩寬樣本**。單一合格者即可選定，多人合格時比較肩寬中位數。OC-SORT 持續逐影格更新，**不重置追蹤器或重新編排 ID**；選定後再建立目標專用 VIDEO 實例，等待有效人物框與可信臉肩連續達標後建立新座位基準。單純 2 秒 VIDEO 重建保留基準。

如需減少一幀漏檢觸發重選，可設 0.5 秒緩衝；如需在追蹤遺失時保留原 ID 等待，可關閉該分支：

```powershell
.\run_pose.bat --auto-reset-seconds 0.5
.\run_pose.bat --no-reselect-on-loss
```

`--no-reselect-on-loss` 只停用追蹤遺失重選。原 ID 仍被觀察到時，2 秒姿態重建與 10 秒姿態失敗重選仍獨立運作；R 可手動重新初始化。

重新選人可能選到其他受試者或成人，OC-SORT 也可能發生 ID 交換。每次完整重選增加 `selection_generation`，CSV 結束舊事件並分開記錄新代次，即使選回相同數字 ID 也不合併事件。不能據此宣稱跨 ID 或跨初始化代次是同一受試者。

## 動作規則

下列為可調整的起始門檻，需使用自己的影片校正。`S₀` 表示固定肩寬參考值；所有座標使用原影片像素。搖頭、揮舞與趴桌缺少必要關鍵點、低信心或身分不確定時回報 `unknown`。離席的離開分支只需有效人物框，歸席才需要可信頭肩；不使用推估的下半身來補成立證據。

| 項目 | 預設條件 |
| --- | --- |
| 搖頭 | 先以約 0.4 秒穩定觀察建立中立參考。鼻子相對耳／眼連線的投影，在最近 2 秒內交替到達左右極值至少 4 次；門檻為臉部尺度的 0.12，兩次至少間隔 0.12 秒。 |
| 單手快速揮舞 | 各腕相對雙肩中點的位移除以 `S₀`；最近 2 秒內主要方向擺幅 0.03～0.25 × `S₀`，至少 2 Hz、3 次完整往返，可信反覆動作跨度至少 1.5 秒，並通過取樣、峰谷與跳點檢查。 |
| 雙手快速揮舞 | 左右手在同一觀察時間窗內各自達標，不要求同方向或同步。 |
| 疑似趴桌 | 約 2 秒正常坐姿建立基準後，頭下降至少 0.30 × `S₀`、頭到任一有效前臂線段距離不超過 0.35 × `S₀`，三條件持續至少 1.5 秒。 |
| 離開座位區 | 鎖定目標後，人物框及可信臉部／雙肩須連續有效至少 2 秒、10 份樣本，才建立固定基準；完成基準後，當幀框與基準框 IoU < 0.5 立即離席，不需骨架。歸席需要 IoU ≥ 0.5、框中心回到基準內與有效頭肩姿態，符合即解除。 |

搖頭的**第一次到達極值算 1 次**：左→右→左→右為 4 次。預設把「超過三次」解讀為至少 4 次極值到達；若要左→右→左即成立，使用 `--shake-min-turns 3`。二維轉向指標不是精確旋轉角度；整顆頭平移不直接當作轉向。

左右手指受試者自身的左右，不是畫面左右。左右手與 `both_wave` 可以同時成立，**不是互斥分類，不能直接相加計算總時長**。預設針對小幅動作；大幅揮手可調高 `wave_max_amplitude`。手腕幾乎不動的指尖動作不在本版範圍。

趴桌代表「頭部下降並靠近可見前臂」，不能證明實體接觸、交叉雙手或睡眠。遮擋中斷成立計時，未觸發完整重選時保留已完成的基準；追蹤遺失或 10 秒姿態失敗造成完整重選時重新校正。起初已趴桌、沒有正常坐姿參考時會等待校正。

座位基準從鎖定一個 `target_id` 後開始收集：**每份框樣本都必須同時有當幀有效 OC-SORT 偵測配對，以及 MediaPipe 可信臉部與左右雙肩**，連續至少 **2 秒、10 份樣本**，才對 `left top right bottom` 各角座標分別取中位數後固定。臉部以有效鼻點為優先，鼻點不足時使用至少 3 個可信臉部點的中位數；所需點的 `visibility`、`presence` 均須至少 **0.7**，座標有限且頭肩位置與人物框、原影片範圍合理。

未完成校正時，人物框、臉部或任一肩膀失效，或來源時間間隔過大，就清除本段樣本與起始時間，重新收集。不能先累積只有人物框的影格，再以最後一幀骨架補足條件。「穩定」指連續有效追蹤臉肩，沒有新增身體靜止或坐姿分類條件。

基準建立後不跟著人物框移動。`IoU` 是交集面積除以聯集面積：當幀有有效人物偵測配對且 **IoU < 0.5**，立即成立離席；此離開分支不需要骨架，不再使用肩膀中點、1 倍肩寬或 1 秒持續門檻。

已離席後，必須同時滿足 **IoU ≥ 0.5**、人物框中心回到基準框內，以及 MediaPipe 有效頭肩姿態，才立即歸席，不等待原本的 0.7 秒。框已返回但骨架不足時，維持「離席，等待骨架確認歸席」。沒有當幀偵測或只有預測框時為 `unknown`，不直接當作離席或歸席。

可按 S 指定基準框，或指定原影片像素 `left top right bottom`：

```powershell
.\run_pose.bat --seat-roi 600 150 1300 900
```

請框**正常坐姿人物的追蹤範圍**，供 OC-SORT 人物框比較重疊程度；此處不是肩膀中點允許活動的區域，也不是只框椅子本體。有效修改會結束目前事件並重建座位基準；取消、空框或跨出影片顯示區時維持原設定。**S 與 CLI 指定框也必須通過人物框及可信臉肩連續 2 秒、至少 10 份樣本的條件**，且校正時人物框中心須在指定框內。

`--seat-roi` 僅供初始選人代次使用；追蹤遺失、10 秒姿態失敗、R 等完整重選會清除舊基準與指定框，重新以當前人物框建立基準。新基準以重新選人後的位置為準，不永久保留影片開頭的座位。切換影片不沿用上一部的 S 框；單純 2 秒 VIDEO 重建保留基準。

站起、前後移動或偵測框尺寸改變也可能使 IoU 降低，這是影像規則，不能確認實際椅面接觸或真實離席。骨架消失、下半身出現、完全出框或追蹤遺失本身都不是離席成立條件。

## CSV 與時間語意

座位基準完成後，離開分支只使用原目標 ID 的當幀有效人物框，即使 MediaPipe 姿態不足或頭肩位置檢查不確定仍可計算 IoU，也不因此取消既有框；遭拒的骨架不會用來確認歸席。完整重選仍會取消基準。追蹤 ID 接錯人時，框規則仍可能誤判。

每部影片的每次執行會建立一組獨立檔案，附執行時間與識別碼，不覆蓋舊紀錄。使用 `--output` 可更改本機輸出位置。

| 檔案 | 說明 |
| --- | --- |
| `…_timeline.csv` | 預設每秒第一個實際分析影格的狀態，包括未知與校正狀態。 |
| `…_events.csv` | 每個分析影格更新各項成立事件，保存確認起訖與中止原因，可同時有多項行為。 |
| `…_metadata.json` | 啟動設定、模型來源、時間語意、紀錄筆數及結束原因。 |

CSV 為 **UTF-8 BOM**，可供 Excel 開啟，時間單位為**原影片秒數**。共同身分欄位為 `target_id` 與 `selection_generation`。時間軸的六個狀態欄位為 `head_shake`、`left_wave`、`right_wave`、`both_wave`、`table_rest`、`seat_leave`；事件檔以單一 `behavior` 欄位記錄對應代碼。

狀態值：`active` 成立、`normal` 有資料但未成立、`unknown` 無法判定、`calibrating` 建立基準／收集樣本、`candidate` 等待持續時間。**未知不代表行為未發生。** 無效的診斷數值以 JSON `null` 表示，不改成 0。

時間軸是**每秒點取樣，不是整秒平均或整秒標籤**。`sample_time_seconds` 是真正觀察時間；`interval_start_seconds`／`interval_end_seconds` 只表示所屬秒桶。跳過的秒數不補造列。兩次取樣間可能有短事件，需搭配事件檔解讀。

事件 `start_seconds` 與 `confirmation_seconds` 都從第一次觀察到 `active` 開始，不回推到真正動作起點。趴桌需先累積 1.5 秒，事件才從確認時刻開始；搖頭與揮舞使用滑動時間窗，事件結束也可能晚於最後一次實際動作。成立狀態區間短於 1.5 秒不代表只觀察了短於門檻的完整揮舞。

`last_active_seconds` 保存最後一筆成立證據；`end_seconds`／`duration_seconds` 是觀察狀態區間。`end_observed=1` 只表示接著觀察到 `normal`。未知、重新選人或結束造成中止時為 0，**不能將中止時間當作真實動作結束時間**。來源時間大幅跳躍時以前次實際觀察切段，不連接未觀察時段。不同身分或初始化代次不合併事件。

本機 CSV metadata 與 `ENVIRONMENT.json` 可能包含使用者影片路徑、環境位置及套件資訊；這些執行產物不屬於儲存庫發佈內容。

## 設定

預設讀取平面 JSON `settings.json`；JSON 使用底線鍵名，命令列使用連字號，**命令列優先**。例如：

```powershell
.\run_pose.bat --input ".\videos" --wave-min-hz 2.5 --shake-min-turns 3
.\run_pose.bat --detector-preset tiny --device cpu --csv-interval 0.5
.\.venv\Scripts\python.exe -B .\experiment.py --help
```

常用參數包括輸入／輸出、初始化時間、肩膀信心、有效樣本數、候選差距、偵測器預設／權重／裝置、各行為門檻、座位區與 CSV 取樣間隔。`--settings` 可選用另一份設定；修改設定後重新啟動生效。

恢復參數：`--reselect-on-loss`／`--no-reselect-on-loss` 控制追蹤遺失後是否重選，預設啟用；`--auto-reset-seconds` 預設 0 秒；`--pose-recovery-seconds` 預設 2 秒；`--pose-reselect-seconds` 預設 10 秒。JSON 對應鍵為 `reselect_on_loss`、`auto_reset_seconds`、`pose_recovery_seconds`、`pose_reselect_seconds`，命令列可覆蓋設定檔。

座位參數：`--seat-baseline-seconds` 預設 2 秒，指人物框與可信臉肩同時有效的連續時間，另需至少 10 份樣本；`--seat-iou-threshold` 預設 0.5，JSON 鍵為 `seat_iou_threshold`。`--seat-roi` 可指定初始代次基準框。舊版 `--seat-departure-ratio`、`--seat-hold-seconds`、`--seat-return-seconds` 及同名底線 JSON 鍵仍接受，但本版 IoU 模式不使用，已從預設設定檔移除。

偵測器預設 `nano` 為 YOLOX-Nano 416；`tiny` 為 416，`s` 為 640。已知 YOLOX 模型採官方 release `0.1.1rc0` 並檢查 SHA256；自訂 `--detector-model` 需符合程式支援的 raw-output COCO YOLOX ONNX 格式，並設定 `--detector-size`，不能直接替換成任意 YOLO ONNX。
